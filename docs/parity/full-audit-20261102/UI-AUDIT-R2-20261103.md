## 先修越界写入、敏感信息和隐藏执行

推荐按以下顺序修复，再处理其余交互差异。前两组直接影响操作权限、数据或费用，不能当成视觉收尾。

1. **收回不应继续发生的动作。** Pad 折叠/收起后仍保留 socket 和 run/refresh/ask 权限；同一 Pad 又同时由专用表面和泛型 overlay 消费（DYN-R2-001/002）。Skills 组开关越过筛选后的可见成员，改写隐藏技能（R2-AUTH-001）；改桌宠体型等无关字段也会重写助理性格（R2-PETA-003）。修复分别落在 guest 生命周期、Skills 的确切成员集合和 personality 变更门禁，主装配只保留一个 Pad owner。
2. **恢复敏感内容与审批依据。** 中文紧邻凭据会漏掩码，reveal 状态按原文在整窗共享、跨消息/会话保留（R2-AU-006/007）；常见委派 shell 审批把请求者和实际工作目录藏在另一分支（CONV-R2-003）。聊天文本 renderer 与审批卡分别修，保留现有 Host/请求身份约束。
3. **保住完整消息与轨迹。** 纯文件消息被空 body 分类丢弃；同名附件去重错误；轨迹复用编辑后的聊天投影，漏掉被替换的历史，并把 steering 当新回合（CONV-R2-001/002/005/008）。Store 保留结构化内容和 durable 轨迹，聊天仍保留正确的编辑替换语义。
4. **纠正保存与取消。** 助理/远程开关取消重启后配置不回滚；自动恢复控件提交整份诊断草稿；普通外观开关滑杆没有按原版即时保存；Whale 默认设置漏接模型/推理控件，保存失败可丢草稿（SETV-R2-001/002/003、R2-PETA-001/002）。复用已存在的单一 writer/事务，不再平行维护另一套状态。
5. **恢复基本完成路径。** 侧栏退出没有可见确认面，在线资料失败又被加成退出硬前提；登录终态错误/过期和离页跟随缺反馈（R2-AU-001–004）。导入扫描同步占用原生输入线程；更新中心缺后台检查/失败重试，升级后还可恢复同版本旧 ready（R2-LIFE-002–004）。

在 Pad 生命周期修复前，**不要把折叠/收起当作停止卡片脚本的动作**。
