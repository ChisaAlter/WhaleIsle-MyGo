# 界面实现纠偏

2026-11-03。**全量实现未完成，`.8` 不是就绪版本。** 下文保留此前源码纠偏结果；只读第二轮清查后，用户授权的全部 54 项已确认缺口和此前明确未闭合的自动化交互已落源码。测试、测试准备、窗口输入、模型请求、构建和发布继续停止；下列改动尚未进入新 EXE。

最新[第二轮清查](UI-AUDIT-R2-20261103.md)保留清查时 54 项未对齐合同与修复顺序。这里列出的上一轮改动不代表其所在整个页面或功能域已经齐全。

第二轮 54 项现已落入产品源码及实际消费者，另补齐已定位的自动化交互与外部功能设置回滚；本轮逐项结果、主装配及继续条件见[执行记录](IMPLEMENTATION.md#第二轮开发责任)。第二轮清查表保留修改前基线，不改成运行通过表。

## 为什么原来的完成判断失效

接口、控件和局部运行链的存在，没有证明原版功能在正确入口、正确作用域和正确页面中完成。此次已找到明确的消费者错误，而非仅有外观偏差：

- 权限配置命令被列入审计消息后，`len(Messages)>0` 被误当作首条对话，草稿欢迎页因此退场。
- 顶栏会话更多被接成插件/市场/启动器菜单；团队入口被接成右栏资源切换。
- 右栏只取得已经打开的 occurrence，遗漏真实注册资源目录；`plugin-native` 又未被实际渲染分支准入。
- 文件树与预览被硬拼为同一页面；从聊天、文件选择器及计划打开的内容写入了不再可见的内部状态。
- 模型“编辑”按钮没有挂到专用供应商编辑器；配置与密钥还使用了互相冲突的两个保存版本。

## 已写入源码的修复

### 草稿、权限和用户文案

- 共享 `ViewState.HasConversationContent()` 排除配置命令审计；欢迎页、提交时目录要求、选择工作区和“无工作目录”的草稿迁移使用同一规则。
- 权限改为专用原生 popover，保留 Host 说明、opaque value、图标、选中、实验标识、busy 和风险确认，不再复用带无关键盘页脚的通用菜单。
- 权限成功只反映在 chip，移除永久 raw 权限顶行；正常页面不再绘制 `会话控制: projection`。命令与控制审计数据仍保留。

### 顶部入口、团队与会话更多

- 普通团队使用原版锚定成员/任务浮层；成员打开复用主会话中的 addressed child 路由，不切到泛型 Agents 右栏。
- 会话更多恢复下载日志及可用时的反馈；插件发现、创建和启动器留在各自入口。
- 日志下载与裸 `/export` 共用认证 Host `/api/session.export`，下载包含子会话与附件的实际 ZIP。原生保存取消保留输入，失败不截断已有文件；不以当前聊天文本代替日志包。
- Project 团队使用独立数据 provider 与共享查看状态；浮层和持续观察侧栏共享范围、搜索、6 成员/5 任务分页、展开和滚动，按 Host/Project/coordinator 隔离。成员在顶部打开主子会话，在侧栏打开同一 pane 的成员资源；pin/unpin 不重置查看状态。

### 右栏和动态资源

- 恢复真实 Start guide、可见新增入口与独立资源菜单；资源关闭与收起分别处理。
- 注册目录独立于已挂载页签，保留 provider/entry 身份、kind、标题、说明、图标、顺序和 availability；同 kind 的第三方贡献不会被固定原生适配器吞掉。
- 按公共 `openTab(kind)` 打开并等待真实 mounted handle 后，才替换发起操作的 guide。关闭使用公共 `close(tabId)`，不调用原类私有方法。
- `plugin-native` 接入实际资源绘制分支。文件树、Diff、选择器、聊天/历史引用、交付物和计划共用独立资源入口，保留原 dirty 状态、Host scope 与不被本地处理时的既有回退。
- 分栏保留旧资源，在新 pane 打开 Start guide，不再复制当前终端/文件 reader 或随意改为 Files。

### Files、Browser、Diff 和终端

- Files 独占目录树，点击文件交独立资源页；树与搜索都遵守 HostOnly，不能读取桌面上碰巧同名的目录。Host 的特殊条目不再被当作普通文件；原本地调用的 local-first 合同保留。
- Browser 去掉重复页签和固定七行工具；主要内容不再被 242 DIP 常驻工具栏挤占，可选工具显式展开，viewport 随实际 chrome 变化。
- Browser sandbox 先前被误列为桌面缺口：实际安装的 Electron carrier 不暴露此可选能力，开关只属于 Web iframe 实现。已按 carrier 纠正，不添加失效控件或降低既有安全策略。
- Diff 首次打开同时读取 patch，无工作区不先探测 Git；逐文件暂存等动作回到差异文件头部，仓库管理不永久挤占阅读区。
- 终端补直接接管/重连、具名 shell 选择；DockKit 和浮动题签复用精确发生项的原位重命名，保留 Enter/失焦提交、Esc 取消及原位错误。

### 模型、插件和市场

- 模型列表使用真实 configurable provider 目录，专用编辑器留在当前模型页；编辑/添加/取消/删除不再跳入泛型 schema 页或展示重复目录。
- 配置先保存并取得确认 revision，再继续引用绑定和 Key 保存；后一步失败保留 Key 草稿，准确提示已完成的步骤，旧独立调用入口保留。
- 插件只读实例页、原生包管理器和精选市场分开；两个包管理入口已接到同一原生 Plugins 主页面。
- 动态插件设置页签读取真实 `settings.plugins.tab` 注册目录，并在主装配消费 ID、标签和顺序；选中精确源页，已访问的隐藏页保留原生命周期，不重复挂载 inventory。
- 模型探测使用当前编辑器未保存的 endpoint、协议和 Key，候选只采纳进同一草稿，仍由同一次保存提交；不再拿独立高级工具替代此入口。首次配置自动展开、账号优先和可用状态使用真实目录、账号与凭据 metadata。

### 对话、计划审批和失败后的操作

- 回合导航使用真实 Host 回合目录和当前阅读位置，不再固定高亮末回合；补上长列表滚动、响应预览和过滤掉 `turn/start` 后的跳转落点。frame 与聊天滚动共用同一列表/折叠投影。
- 计划审批只放标题与摘要，完整原文首次可见时打开右侧计划资源；自动打开标记由 Host/Agent/请求身份共享，隐藏不消费，重挂载不反复抢焦点，手动预览继续可用。
- 普通问题失败后保留修改、跳过和提交；编辑清理旧失败，父/子会话从当前草稿重新构造答案，而不是只能重发旧回答。审批/计划的原选择重试保留。
- “已编辑文件”只由真实非空 Host 变更摘要决定，不再从工具参数推算已完成写入，也不抹掉摘要读取错误。

### 自动化任务

- 新建复用现有全局工作区/草稿入口，不直接调用裸 CreateSession；详情的“任务不存在”须等本次导航后的成功全目录读取。
- 重复/Cron/星期使用面向用户的标签；频率、规则时区、设备时间、记录时间和过期倒计时消费原版对应语义。时区改为可搜索、最近项和保留确切别名的锚定菜单。
- 保存中即时禁用编辑/取消，失败保留草稿并提供可操作提示，不留下永久成功行；任务资源关闭回到真实 close/guide 路径，而不是隐藏 Files。
- 原版这里没有独立启停/立即运行按钮，未将生命周期过滤器伪造成新操作。
