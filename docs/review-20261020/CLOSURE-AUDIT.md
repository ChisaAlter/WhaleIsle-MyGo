部分/未闭合（6）：

- **远程（#22）**：机器/文件页与配对流程未重做。

## 5. 视觉与特效

已闭合（11）：表面 alpha 模型（采样玻璃 + 圆角）、菜单/弹层采样材质与 Reveal 淡入、壁纸管线与遮罩、动效 token（overlay/popover/swap/flip）、指针特效（框架已实现 + 配置桥）、金属漆（框架接管）、composer beam、渐变/强调色、字体阶梯、深色实机跟随系统、150% DPI 修复（runtime 归一 + 实机验收）。

部分/未闭合（5）：
- **透明主题（P1 #4）**：`DrawGlass` 对透明主题直接返回，细节未验证。
- **token 深度（P2 #6）**：主题 token 未逐项对齐原版 `--dsw-*`（仅覆盖用到的）。
- **滚动条（P2 #13）**：已有 5 DIP + hover 色 + 常驻；但无 per-container 样式、终端插件自绘不吃主题、无滚动位置读取（`w5-scrollbar.md`）。
- **100%/125% DPI**：代码路径与 150% 相同（scale 归一），但未做实机验收。
- **误报更正**：指针特效（#10）与金属漆（#11）在原版/框架里本就存在，Wave 2 复查后关闭，不计入未闭合。

## 6. 结论

- **P0 全部有实现**，且经过多轮实机/软件渲染验收（hero、深色、150% DPI、侧栏、组件画廊）。
- **剩余工作集中在「功能界面的结构还原」**：插件市场、插件列表、定时任务、远程、桌宠、Project。这六块此前只有本地化/尺寸级修补，没有按原版组件重做，是当前最大的观感差距来源。
- 视觉层剩余为长尾：透明主题、token 深度、滚动条 per-container、100/125% 实机验收。
- 建议下一阶段（Wave 9）按「市场/插件列表 → 定时任务 → 远程 → 桌宠/Project」顺序各做一次结构重做，每块配一张组件画廊截图。
