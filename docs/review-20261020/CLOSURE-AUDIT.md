部分/未闭合（5）：
- **插件市场（#19）**：卡片结构已重排，但安装流程细节与远程图标未接（图标用首字母方块）。
- **远程（#22）**：机器卡片/编辑器/文件页/配对三步已重做；文件元信息（大小/时间/权限）与上传下载需 `internal/store/remote` 协议字段。

## 5. 视觉与特效

已闭合（13）：表面 alpha 模型（采样玻璃 + 圆角）、菜单/弹层采样材质与 Reveal 淡入、壁纸管线与遮罩、动效 token（overlay/popover/swap/flip）、指针特效（框架已实现 + 配置桥）、金属漆（框架接管）、composer beam、渐变/强调色、字体阶梯、深色实机跟随系统、透明主题（W9：0% 底色 + 保留 hairline/文字 + 首次生效抬 blur 20）、150% DPI 修复（runtime 归一 + 实机验收）与 100/125/200% 框架测试（W10：像素 host 归一到 DIP、绘制乘 scale、1× 恒等、scale≤0 兜底）。

部分/未闭合（2）：

- **token 深度（P2 #6）**：14 个 token 已 pin 测试并全部一致；`label-secondary` 未建模、浅色 Field 与 layer-1 差异等 6 项已列清单（部分需改 64 个调用点）。
- **滚动条（P2 #13）**：已有 5 DIP + hover 色 + 常驻；但无 per-container 样式、终端插件自绘不吃主题、无滚动位置读取（`w5-scrollbar.md`）。


误报更正：指针特效（#10）与金属漆（#11）在原版/框架里本就存在，Wave 2 复查后关闭，不计入未闭合。

## 6. 结论

- **P0 全部有实现**，且经过多轮实机/软件渲染验收（hero、深色、150% DPI、侧栏、组件画廊）。
- **剩余工作集中在「功能界面的结构还原」**：桌宠（窗口/渲染）、Project 完整面板与画廊、市场的安装细节与图标、远程的文件元信息/上传下载（需 store 协议字段）、设置面板密度、桌宠。插件市场/列表/定时任务/远程主体已在 W9 重做。
- 视觉层剩余为长尾：token 清单 6 项、滚动条 per-container（终端插件自绘/无滚动位置读取）。
- 建议下一阶段按「桌宠 → Project 完整面板 → 市场安装细节 → 远程 store 字段 → 设置密度」顺序收口；视觉长尾可与之一并做。
