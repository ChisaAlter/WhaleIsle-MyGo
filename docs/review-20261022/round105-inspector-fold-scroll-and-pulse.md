# Round 105 — Inspector fold anchoring, trailing extent and row pulse

## Result

The native Inspector now keeps the measured disclosure header at its visual position when folded, preserves a useful parent or surviving row when live blocks close, and puts the required blank extent after all data rows. Appended rows consume that blank before extending the list. Manual folding stays in manual follow mode; ordinary scroll and programmatic reveal classify the final position using the reference's inclusive40DIP near-tail rule. Follow Latest clears the retained blank and follows the compact end. Cross-section programmatic navigation updates the sticky ancestor band.

Row highlights now match the reference700ms linear background fade. Chat Group flashes on new/updated visible records; Raw Log flashes only on explicit navigation. Initial history and ordinary selection stay quiet. Reduced motion suppresses the pulse. The row keeps its clock when it becomes or stops being a sticky header, and changing lifecycle disclosure alone is not a record update.

[Default executable](../../whaleisle.exe) is updated to pass249. Commit and evidence cover this Inspector behavior only. The complete Whale Isle parity goal remains active.

## Source-backed implementation

Reference behavior is defined in [table layout](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/src/client/views/table-layout.ts), [table effects](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/src/client/views/InspectorTable.tsx), [hierarchy](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/src/client/views/table-model.ts), [presentation modes](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/src/client/views/View.tsx) and [CSS tokens](../../reference/electron/vendor/deepseek-harness/packages/client/ui-theme/src/styles/design-platform.css). The independent source audit also read the reference [layout cases](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/tests/table-layout.client.spec.ts), [scroll cases](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/tests/table-scroll.client.spec.tsx) and [row update case](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/tests/table.client.spec.tsx).

The new native [layout owner](../../internal/ui/frame/session_inspector_layout.go) uses the same30DIP row/header geometry. Its formulas include the fixed header even though the native List owns only the body; numerical scroll offsets are the same in both implementations. A manual anchor uses the clicked row's measured sticky position. Automatic preservation requires fewer visible rows plus a surviving explicit open→closed transition. It chooses the first unobscured previous row, then its nearest retained ancestor if necessary. Retained minimum extent is carried across subsequent source changes and is dropped once natural row extent fills it. There is no blank area between actual records.

The [table integration](../../internal/ui/frame/session_inspector_table.go) applies padding before layout and explicitly coordinates the toolkit's key anchor with the view's measured anchor. A small [ListState.ScrollToOffset API](../../third_party/mygo/ui/list.go) requests an offset even if its numeric value is unchanged; a same-offset key-shift regression verifies this. It clamps to content bounds and changes no normal List follow policy. Its [owner documentation](../../third_party/mygo/docs/ui/list.md) describes when to use it. MyGo architecture was read before this toolkit change; no backend/cgo changes are involved.

Follow mode is view-local tail/scroll/manual. Wheel/key/scrollbar moves use remaining<=40DIP outside manual mode. A programmatic fold uses the new extent, not stale pre-fold bounds. Reveal/filter movement is classified after List layout using the actual final MaxY; an unchanged reveal does not synthesize a scroll event. Visibility observation schedules a second build when end/center requests move to a different hierarchy, keeping the sticky band synchronized. [Filter confirmation](../../internal/ui/frame/session_inspector_controls.go) clears spacing; Load Earlier leaves it intact. [Navigation](../../internal/ui/frame/session_inspector_navigation.go) resets spacing, opens ancestor overrides and centers once; Follow Latest clears spacing and requests end. Binding/mode changes discard geometry and animation state.

The [pulse owner](../../internal/ui/frame/session_inspector_motion.go) tracks arrivals from the complete source, rather than filtered or folded rows. First nonempty history is historical, subsequent new keys get one timestamp, and removed keys are pruned. Mounted row pulse state is shared by record key across normal and pinned presentation and pruned when no longer built. The comparison includes display metadata/raw value/summary/time, excluding disclosure-only metadata. Record, arrival-state, flash-policy and reveal-generation changes cancel the previous pulse as reference effects do. Each repeated reveal creates a new pulse generation. Painting runs on the renderer's frame clock rather than rebuilding the hierarchy every animation frame; expiry restores ordinary selection/hover/sticky styling.

The highlight has its own [semantic theme role](../../internal/ui/theme/theme.go), light rgb211,226,255 and dark rgb67,69,74. [Custom-family derivation](../../internal/ui/theme/family_palette.go) uses the original contrast-dependent strong accent wash and honors an explicit highlight override. It does not substitute the different Bubble role. Runtime ReduceMotion is read from UI preferences, without new preference disk reads.
