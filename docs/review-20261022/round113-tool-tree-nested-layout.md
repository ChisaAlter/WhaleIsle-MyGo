## Native implementation and regressions

[ToolMessageView](../../internal/ui/chat/tool_lifecycle.go) re-enters same-pass child containers through synchronous Element.Children. A local work stack uses parent indices into a local Element slice; no Element is stored in persistent state, structs or layout callbacks. Keyed call wrappers retain sibling identity. The accepted-pointer set prevents duplicate/shared/back-edge mounts and empty gutters for nil/cycle-only children. The business builder does not recurse, but toolkit layout/paint still recursively traverse its real nested UI; this round makes no extreme-depth stack or performance guarantee.

Child containers use automatic stretch width, not100% width plus a left margin, so their right edges match the parent. The root final2-DIP margin moves to its outer native wrapper to model the observed margin collapse; nested call wrappers keep it internally. [Inspector boxes](../../internal/ui/chat/session_inspector_tools.go) now observe whole wrappers directly and remove the redundant union allocation and parent indices from the prior flat-tree adaptation. Reverse preorder still prioritizes descendants; original root-owner reverse matching is unchanged.

Five [new layout regression groups](../../internal/ui/chat/tool_tree_layout_test.go) check exact nested boxes, following-flow112 versus root110, continuous light/dark connector pixels, own-body expansion preserving descendants, local disclosure state after sibling insertion, depth0–10,520/350/220/100-DIP widths, finite nonnegative sizes, malformed pointer graphs, root-only, and scale-dependent hairline geometry at1/1.25/1.5/2/3/4. Existing read-only history now asserts real child titles/state and absence of the removed parent-ID label. The prior nested picker/reveal tests—including cold/tall owners, partial clips, reduced motion, interruptions, transcript unfolding and pending history reparent/source-key changes—pass without weakening their behavior assertions.
