## Shipped behavior

[The terminal model](../../internal/ui/chat/terminal_model.go) accepts the exact names `bash`, `pwsh` and `terminal_send`, parses an arguments object, validates each optional field before selecting the persistent-shell arm, and takes output from exactly one raw text block. Generic execution errors, malformed schemas, multiple/nontext result blocks, settled persistent calls and exact output-spill notices use generic IN/OUT. Unknown aliases such as `shell` stay generic. Successful background shell results render a command-only banner, without treating a job acknowledgement as output or an exit. Running calls use only an absolute request cwd; settled root calls may resolve the session/workdir, nested calls may not borrow that root cwd, and recorded absolute result metadata wins verbatim. These calculations never access the filesystem or change stored events.

Exit markers are parsed only at the final newline-prefixed position, with signal taking precedence over signed integer or literal-null status. Standard foreground single-text output without a marker implies exit0; terminal_send output stays raw and gains no inferred exit. Nonzero/null/signal settlement changes only display status, preserves the authored description, and adds the neutral [exit badge](../../internal/ui/chat/terminal_badge.go) immediately after it. The persisted call remains completed. Generic tool errors retain the output-first-line error summary. Header and generic rendering are integrated in [the lifecycle](../../internal/ui/chat/tool_lifecycle.go), [tool body](../../internal/ui/chat/toolrow.go), [header](../../internal/ui/chat/tool_row_chrome.go) and [summary model](../../internal/ui/chat/tool_row_model.go).

[Terminal rendering](../../internal/ui/chat/terminal.go) uses margin4/0/4/4, radius16, BorderL1 hairline with device-pixel used width, CodeBlock fill, a30px gutter and default run-state dot. Command rows use code11/18 and an8px prompt gap; only the first row names cwd, later rows use `$`. One final command terminator is removed. Command content is capped at150px plus18px padding; the header divider is separate in native layout. Status and Copy reserve their intrinsic widths and clamp to top0 after the banner scrolls past its initial9px inset. Output stays preformatted, mounts all lines, and scrolls horizontally/vertically with224px content plus24px padding; there is no middle-line expansion button at this ToolRow site. Settled invisible output shows the localized40px placeholder section; running and background cards remain banner-only when appropriate.

Current installed ToolRow passes neither a `copyText` override nor `runStateDot:false`. Consequently the card's Copy button copies the exact parsed output, including ANSI bytes, trailing whitespace and hidden lines, rather than command+output. It appears only after nonempty foreground settlement, shows localized Copied feedback for1second and ignores a second activation during that interval. Native focused Enter is checked before and after the feedback window. The addressed read-only reader retains its separate whole-call evidence copy through the service clipboard API. [Locale-owned terminal labels](../../internal/ui/i18n/catalog_terminal.go) cover status, empty output, terminal_send and accessible groups.

[Shared inert ANSI replay](../../internal/ui/widgets/ansi/ansi.go) now supplies conversation cards and the existing [installation-output adapter](../../internal/ui/pluginmanager/install_ansi.go), avoiding two terminal-control parsers. It replays carriage return/backspace/erase-in-line/wide columns before styled text, strips inert OSC/other controls, preserves styled raw output as the copy payload, maps basic foreground colors to semantic tokens, and retains explicit foreground/background pairs. Existing plugin-manager color mapping is retained by its adapter. [ANSI tests](../../internal/ui/widgets/ansi/ansi_test.go) and the existing install tests cover this reuse.
