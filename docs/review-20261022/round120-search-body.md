## Production changes

[The pure model](../../internal/ui/chat/tool_search_model.go) derives a card only for successful settled root grep/glob with a retained call head, valid typed arguments and root result metadata. Grep rejects an exactly empty pattern; glob rejects JavaScript-trim blank patterns. Optional path must be a nonblank string. Grep include rejects literal leading`!`, trim-blank and commas outside braces; it preserves the installed brace-depth quirks rather than imposing extra glob syntax validation. Metadata requires shape, boolean truncated and nonnegative Number.isInteger total. Paths, file paths and match text remain verbatim, including empty/control/URL-like strings, duplicates and ordering. Positive match line numbers retain IEEE-754 integer semantics beyond native/safe-integer bounds. No total/count/order/path-authority consistency checks are added. Derived slices are independent and raw events stay unchanged.

[The search primitive](../../internal/ui/widgets/markdown/tool_searchblock.go), [chat adapter](../../internal/ui/chat/tool_search.go) and [localized labels](../../internal/ui/i18n/catalog_tool_search.go) draw a radius16 borderless card. Chat margin is4px0 4px4px, matching installed static stylesheet followed by appended ToolRow stylesheet. Header38px uses padding9px14px and gap12px; summary and text Copy use fixed13px/20px interface font. Body padding is8px14px12px0; baseline code font11px/19px responds to the code-size delta. Every file/path/match row has minimum22px, increasing only when its text line height exceeds22px. File paths use weight600, file/count gap8px and14px horizontal padding. Match line numbers use tertiary ink and the exact number/colon/space prefix. Empty results show localized No results with no Copy; a zero-match file remains a visible file group with Copy. Search has horizontal overflow and no wrapping toggle. Long rows use measured text width so content contributes to the scroll range while the banner stays stationary.

Each file group has independent collapse state indexed by retained file order. The whole card caps the resulting flat rows at8:head4,fold control19px,tail4. File titles consume row slots. If the tail starts inside a file absent from the head, its title replaces the first natural tail match; a file already represented in the head gets no duplicate title. Hidden count is flat row count minus8. Expanded mode shows all rows then the collapse control, and local group changes recompute that count. Statistics always count retained metadata matches/paths and all files, independently of local collapse/fold. Truncated summaries include total; other summaries ignore total, including inconsistent recorded totals.

Copy uses every retained group and match, even when hidden or locally collapsed. Paths join withLF; matches serialize path then lineNumber+colon+space+line; files join with twoLFs. Whitespace/empty/duplicate values remain intact. A one-second feedback guard prevents duplicate writes. Native clipboard write returns void, so native feedback still assumes success; refusal behavior is certified only by the browser fixture's in-memory adapter. Truncated recovery filters string text blocks and joins them withLF, omitting only the exact empty result. It is a dedicated sibling after the card, in fixed13px/20px tertiary interface text. Nontruncated text does not become recovery.

[Lifecycle wiring](../../internal/ui/chat/tool_lifecycle.go), [expandability/link handling](../../internal/ui/chat/toolcard.go) and [body dispatch](../../internal/ui/chat/toolrow.go) suppress duplicate args, IN/OUT and auxiliary links for valid keyed search cards. Invalid or legacy keyed results retain output-only generic fallback. The read-only evidence view retains its existing full evidence path. Search result paths do not open files or acquire filesystem authority.
