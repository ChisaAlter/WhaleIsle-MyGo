# Round254 · Hero 标题行 slogan x（窄徽标后的右漂）

round249 之后 slogan 起点在 harness 里是 772.64，原生 765.33（+7.31），而徽标 x 已经与原生一致（936）。本轮量到原因并修好，**实机 UIA 已确认 slogan/badge 与原生完全一致**。

## 1. 原因（不是居中，是行内分配）

原生标题行在 1440 宽下：

| 元素 | 原生 | 修复前 |
| --- | --- | --- |
| slogan | x=765.33, w=156.67 | x=772.64, w=156 |
| 大肥鱼版 | x=936, w=48.67, h=15.33 | x=936, w=49, h=15.4 |
| slogan→徽标间距 | 936 − 922 = **14** | 936 − 928.64 = **7.36** |

即：徽标右缘已对齐，slogan 却晚 7.31 开始——因为**行内两段间距的分配**与原生不同（鱼↔slogan 10 / slogan↔徽标 7，原生约 2.69 / 14.31，总和相同）。整行是居中的，所以总宽不变时中心不动，只要重分配这两段间距即可。

## 2. 修复

`internal/ui/frame/conversation_phase.go`：

- 外层行 `Gap(10)` → **`Gap(2.69)`**（fish ↔ slogan）
- 内层行 `Gap(7)` → **`Gap(14.31)`**（slogan ↔ 徽标）

两者之和不变（17.0），因此行宽、居中位置、行高（foot 22.3 / 栈块 41.34 / 卡片 155.34）都不受影响。推导：设两段变化 x、y，居中行的 slogan 位移 = (x−y)/2，徽标位移 = (x+y)/2；要求 slogan −7.31、徽标 0 ⇒ x=−7.31、y=+7.31。
