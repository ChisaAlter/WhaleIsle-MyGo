## Behavior and implementation

[The pure model](../../internal/ui/chat/tool_read_model.go) follows the current installed read-card-model and raw-tool-call functions. It requires a retained, settled successful root read, valid object arguments, one text result, the exact LF file envelope and valid metadata. Metadata supplies the literal display label, returned text, true file numbers, total and optional grammar hint; the envelope only validates format. The original accepts empty metadata paths, noncontiguous increasing numbers, empty windows beyond EOF, exponent-form JSON integers and rounded JavaScript integers. The model preserves those behaviors, with an explicit native-int bound for stored totals/numbers. It never opens or resolves files and does not mutate retained events.

[The native primitive](../../internal/ui/widgets/markdown/tool_readblock.go) starts with wrapping disabled. It uses the complete window's maximum number width, at least3ch, plus12DIP before source text; gutter text is neither selectable nor exposed to accessibility. Rows retain19DIP minimum height for blank text. Above the chat cap8, the card renders head4/fold/tail4; expanded content ends with its collapse button. The shared toolbar has24×24 controls,14DIP icons,42DIP header, padding10/18/8/22, body padding6/22/20, no sticky positioning and no260DIP body cap. Known hints use the installed alias allowlist and the existing native Chroma palette over the whole returned window. Unknown/absent hints remain plain text and display the localized code-block label.

[The chat adapter](../../internal/ui/chat/tool_read.go), [lifecycle](../../internal/ui/chat/tool_lifecycle.go), [body selection](../../internal/ui/chat/toolrow.go) and [disclosure](../../internal/ui/chat/toolcard.go) use this preset only for the keyed main read caller. Invalid metadata falls back to OUT alone, with no IN JSON or duplicate file/path card. Pending reads without output/card remain non-expandable. The source receipt remains available in the read-only/Inspector evidence surfaces. Copy joins every returned text with LF, including hidden middle and final empty row, omits the control for zero returned rows, and uses a one-second copied guard. [Read locale copy](../../internal/ui/i18n/catalog_tool_read.go) matches installed common/read labels, including Chinese “代码块”, “复制成功” and “取消自动换行”.
