## Native changes

[Header rendering](../../internal/ui/chat/tool_row_chrome.go) uses ButtonBase for expandable rows and an ordinary Row otherwise, preserving pointer/Enter/Space behavior without the framework button's hover fill. Its context key is set before reading input, so later Key mutation cannot lose clicks. The full row accepts clicks, including its empty right end. Business glyphs, chevrons and code artwork use the original regular16-unit SVG paths from [icons](../../internal/ui/chat/tool_icons.go) and [row icon selection](../../internal/ui/chat/tool_row_icons.go). Unknown/coarse aliases keep the original generic glyph and wire name instead of silently selecting an unrelated first-party icon.

The [row model](../../internal/ui/chat/tool_row_model.go) and [locale catalog](../../internal/ui/i18n/catalog_tool_rows.go) map exact case-sensitive wire names, including Pwsh, read_image, Grep, Glob, web search/fetch and lifecycle tools. Summaries use full Arguments and Output, preserve literal first lines/whitespace and do not pre-truncate at120 runes. They prioritize complete file_path for file variants, description for nonfile variants, search query arrays and original per-family fallback fields, then first nonempty string in JSON insertion order. Duplicate object keys retain their original position and final value. Unknown names prefix the summary. Preparing incomplete JSON keeps its raw first line because the native model does not yet provide the original lazy argument reader.

[Generic input/output](../../internal/ui/chat/tool_io.go) implements the measured dimensions, colors, selectable full payloads, separate scroll states and sticky captions. Caption text uses the same16px line frame as the body. Main generic cards no longer mount nested Arguments/Result disclosures plus repeated section/whole-call copy seats. [Card integration](../../internal/ui/chat/toolcard.go) leaves specialized terminal/file/search/web/todo bodies in place and moves owner content/Inspect after the body. Preparing cannot mount a body, and an empty settled call does not become expandable solely because an Inspector callback exists. Existing inspect-dispatch fixtures now supply actual argument evidence; real CallID and read-only navigation assertions remain intact.

[Result block formatting](../../internal/ui/chat/tool_images.go) keeps text blocks verbatim, including trailing whitespace and empty text, and formats nontext blocks as complete pretty JSON. [Paired lifecycle output](../../internal/ui/chat/tool_lifecycle.go) no longer trims text or appends a duplicate structured error reason when content exists; only an empty block list falls back to `name: code`, matching the installed result model. Gallery-owned validated images retain their existing path; read-only history retains complete attachment evidence in its copy action.

[Disclosure presence](../../internal/ui/chat/toolrow.go) reuses the existing context presence mechanism: opacity completes in100ms, while an inert toolkit paint copy and empty layout seat retain the exiting body for200ms. No height interpolation is requested. Closed body callbacks no longer run. Reduce-motion removes the retention hold. The existing nested-layout regression now advances200ms before asserting restored child positions. Independent read-only source review found a concrete running-font bug: the shimmer measured/painted using the interface font while settled text used Chat.Family. The optional Font member in [TextShimmer](../../internal/ui/widgets/text_shimmer.go) fixes those two tool-row calls while preserving empty-font behavior for current callers.
