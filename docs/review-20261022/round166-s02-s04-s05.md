## S02 安装前磁盘空间预检 —— **fixed**

原生规格（install-space.js:6-11,20-26）：`SPACE_RESERVE = 256 MiB`、`formatBytes` 输出 `X.XX GiB`、从目标目录向上找第一个可 `statfs` 的祖先（目录还没创建也能估）、`ENOSYS/ENOTSUP/EINVAL` 返回 `checked:false` 而不是当成 0、空间不足时抛出带目录与两段容量的中文文案（`code: ENOSPC`）。

改动：
- 新增 [`internal/desktop/market/space.go`](<C:/AI/WhaleIsle-MyGo/internal/desktop/market/space.go>)：`InstallSpaceReserve = 256 << 20`、`FormatGiB`（`%.2f GiB`）、`CheckInstallSpace(dir, size)`——`filepath.Abs` 后逐级向上，`os.ErrNotExist` 时继续上溯，其它错误返回 `ErrSpaceUnsupported`；不足时返回与原生同义的文案「磁盘空间不足：<dir> 所在磁盘可用 X.XX GiB，本步骤预计需要 Y.YY GiB（含预留空间）。请释放该磁盘空间后重试。」。`freeBytes` 是测试接缝。
- 平台实现：[`space_windows.go`](<C:/AI/WhaleIsle-MyGo/internal/desktop/market/space_windows.go>) `GetDiskFreeSpaceExW`（取 free-to-caller）；[`space_unix.go`](<C:/AI/WhaleIsle-MyGo/internal/desktop/market/space_unix.go>) `syscall.Statfs`（`Bavail*Bsize`）。无 cgo。
- 接线：[`install.go`](<C:/AI/WhaleIsle-MyGo/internal/desktop/market/install.go>) `InstallSpecContext` 在「Node/harness 就绪」检查之前调用 `CheckInstallSpace(cfg.ProfileDir, 0)`——下载前失败即返回错误；此处下载体积未知，因此强制的是 256 MiB 预留（与原生的「含预留空间」语义一致）。
- 测试 [`space_test.go`](<C:/AI/WhaleIsle-MyGo/internal/desktop/market/space_test.go>)：2 GiB 通过；恰好 `reserve+size` 通过、少 1 字节失败且文案含两段 GiB；负数尺寸拒绝；目标目录不存在时先探自己再上溯（探针顺序断言）；不支持的文件系统返回 `ErrSpaceUnsupported` 而非 0。

门禁：`go test ./internal/desktop/market` ok；`GOOS=linux/darwin go build ./internal/desktop/market` 均 exit 0。

## S05 插件崩溃取证分类 —— **fixed**

原生（plugin-forensics.js:12-16）：`GENERIC_OOM = /heap out of memory|js heap|allocation failed|oom\b/i`、`GENERIC_PORT_EXCLUDED = /\blisten\s+eacces\b/i`、`GENERIC_PORT = /eaddrinuse|address already in use/i`、`GENERIC_NODE = /node['"]?\s+is not recognized|cannot find node|enoent.*node(\.exe)?\b/i`，判定顺序 OOM → port-excluded → port-in-use → missing-node。

MyGo 之前：`internal/startuprec/forensics.go` `genericCause` 用子串表，缺 `oom\b`（只认三种长写法）与 `enoent.*node` 形式，`node` 识别只覆盖几句固定文案。

改动：把四个原生正则原样移入 `genericCause`（顺序、大小写不敏感、词边界都保留），保留原有 `session-cache` 兜底；`isBuiltin` 与原生 `isInBoxPackageName` 语义已一致（含 `desktop-plugins/install-dsh-plugin` 路径标记），未改。

测试 [`forensics_generic_test.go`](<C:/AI/WhaleIsle-MyGo/internal/startuprec/forensics_generic_test.go>)：9 组表（含 `Killed: oom`、`listen EACCES`、`EADDRINUSE`、`ENOENT ... node`、`'node' is not recognized`、无匹配的 TypeError），并显式记录原生 `oom\b` 的副作用：`room service` 也归为 oom（与原生一致，不是 MyGo 新引入），`zoomed` 不匹配。
