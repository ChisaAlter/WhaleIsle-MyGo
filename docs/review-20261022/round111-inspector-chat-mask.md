# Round 111 — Inspector Chat picking mask

## Result

Inspector picking now uses a transparent mask above the painted main Chat flow. Starting the gesture preserves message geometry; hovering previews the painted occurrence with 15% accent, a 1-DIP outline and a 4-DIP corner radius. Primary release submits the occurrence to the existing loaded-row matcher. Secondary and middle presses are consumed. A rejected match stays armed. Successful selection, Escape, window blur, binding replacement and hidden Chat retire the gesture; controls outside the mask keep their own input and focus.

The default executable is pass255, 85,267,456 bytes, SHA256 `D7BB8177520B7B9DC7A77BB294F3CA52C398377520DAE9C8910AA2988E28A768`. [Build identity](evidence/inspector-pass255-build.json) records the default/numbered executable hashes and unchanged protected runtime identities. The full layout, UI, function and motion parity objective remains active.

## Native implementation

[The picker](../../internal/ui/chat/session_inspector_picker.go) overlays the last painted clipped flow area, preserves existing keyboard focus, consumes the underlying pointer gesture, and forwards native DIP wheel deltas to the transcript ScrollState. Wheel forwarding uses the original picker's raw delta axes after suppressing default behavior; it does not apply MyGo's ordinary Shift-wheel remapping. Modifier-wheel interaction was not separately browser-tested. Its hit list contains only painted message occurrences; full target metadata is decoded on primary release. [Painted geometry](../../internal/ui/chat/session_inspector_reveal.go) refreshes that list on every paint and clears previews when viewport/scroll or a hovered row changes. Chat reuses its existing source projection for Inspector navigation instead of computing a duplicate full projection.

The [frame handoff](../../internal/ui/frame/session_inspector_pane.go) invalidates after consuming a submitted pick, including when the selected row was already centered. Acceptance calls CancelPicking, clears a held press/preview and rebuilds away the mask. The handler also rejects stale inactive gestures. [An integration regression](../../internal/ui/frame/session_inspector_pick_test.go) selects the same production disclosure twice, verifies selection never opens it, and verifies the immediately following ordinary click does open it. The initial test assumed the completed-turn label for an active fixture; its setup now uses the actual active-process label.

[Toolkit input](../../third_party/mygo/ui/input_observer.go) adds passive blur observation and build-scoped CaptureKeyDown, with last-registered priority before focused controls/window shortcuts. Captured keys still publish current modifiers and retire physical chords. [KeepFocus](../../third_party/mygo/ui/element.go) exposes the toolkit's existing focus-preservation flag through the generated checked facade. The Windows backend now honors a consumed WM_SYSKEYDOWN even when text input is active; unconsumed Alt+F4, Alt+Space and F10 retain native dispatch. A focused backend regression calls that translation path with active/inactive text clients.

Native child pages are temporarily clipped or hidden while the main Chat mask owns input. Expanded dialogs remain independently usable. [OpenUI media](../../internal/ui/chat/openui_media.go) distinguishes transient Inspector masking from offscreen teardown: it hides the same private host and preserves its lease, then presents that same instance on cancellation. An interface-backed host probe verifies instance/state retention and that actual suspension still closes it. This is lifecycle-unit evidence, not a real YouTube playback acceptance run. The temporary empty-clip approach found during review was replaced before the final build to avoid resetting playback state.

## Remaining differences

The mask implements native main-row/group picking, not nested PTC child geometry, every original Turn/Step container or nested process-body wheel forwarding. Embedded native child content is hidden during picking because sibling HWNDs cannot sit below a canvas mask; original browser descendants remain visually present. Real private-media playback and final native desktop hover remain unverified. Hover hit testing is bounded to painted rows, but the native input handler still requests a full UI build for each consumed move; full-history projection/table work and end-to-end latency are not certified by this round.

The typed/lazy Chat object graph, cycle handling/paging50, transient-sequence retention, result-only/toolCallId-only limitations, nested child Inspect identity, shell/caption/tabs/fonts/material/controls/motion parity and production Host startup/shutdown remain open. The earlier unrelated settings tests, toolkit allocation/ellipsis/Linux-vet failures and shutdown hang from [Round109](round109-inspector-target-coordinates-and-ownership.md) were not rerun or counted as passing. This round's partial desktop evidence does not complete the overall parity objective.
