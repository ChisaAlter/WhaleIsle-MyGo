## 2. 实跑发现并修复

### F-A 设置页泄漏内部状态名 `settings document opened`

- 位置：设置·模型页，识图设置下方。
- 现象：直接显示 store 的内部动作字符串，中文界面里出现英文诊断。
- 原因：`LastAction` 直接渲染，而 store 用 `settings document opened` / `settings document updated` / `openSettingsDocument: ...` 记录协议事件。
- 修复：新增 `settingsActionText`，把三种内部动作映射成「设置已打开 / 设置已更新 / 无法打开设置文档：…」；14 个设置页的 `LastAction` 全部走该映射。
- 回归：`TestSettingsActionTextHidesProtocolNames`。
- 实机：`audit-model-fixed.png` 中该行已消失。

### F-B 鲸鱼娘设置页直接显示 WebView2 原始错误

- 位置：设置·鲸鱼娘，页面顶部。
- 现象：`mygo: failed to load whale-pet://localhost/index.html: navigation failed (COREWEBVIEW2_WEB_ERROR_STATUS 14)`。
- 影响：中文产品界面出现内部协议/错误码；且错误显示在“聊天与能力”标签，与桌面形象无关。
- 修复：仅在“桌面形象与行为”标签显示友好的「桌面形象加载失败，请重启应用重试。」，原始错误降为 Tooltip；桌宠窗口错误同样改为友好文案 + Tooltip。
- 实机：`audit-pet-fixed.png` 中原始错误已从默认标签消失。
