# 全量差异审查：MyGo鲸屿 ↔ 鲸屿本体 0.3.9

日期：2026-10-22  
对照：Electron 鲸屿 0.3.9（`C:\软件\Whale Isle` 的 `app.asar`、`packages/client/*`、`Modal.module.css`、`PluginManagerPage.tsx`、locale）与当前 MyGo 源码/`whaleisle-pass121.exe`。  
方法：页面与功能清单逐项盘点；弹窗按 `ui.DialogBase` 全量统计；样式查参考 CSS/JS；交互与动效查实现与回归测试；已有 1440×920 证据复核。

> 这是一次**结构级全量审查**，不是逐像素截图比对。参考窗口在 150% DPI 下超出屏幕，逐像素证据仍受 Host 门禁限制（见 R7）。

## 1. 结论

- 没有整页缺失的主页面。MyGo 的 4 个主页面、12 个设置页、10 类右侧面版、47 个弹窗都有对应实现。
- 34 条结构性差异（D1–D34）已关闭；R1、R2、R9、R10 也已关闭。
- 剩余差异集中在 **3 个视觉/动效细节**、**1 个有意的页面取舍**、**6 个环境或实机验证项**。
- 当前最明显的日常观感差异不是布局，而是 **Markdown 块级节奏** 和 **流式文字的淡入动效**。

## 8. 建议优先级

1. **P1**：Markdown 块级节奏（U1/L1）——每天都影响阅读。
2. **P1**：流式文字淡入（M1）——回答生成时最明显的“原生感”差距。
3. **P2**：补模型凭据，跑通真实对话与模型选择（F2）。
4. **P2**：在可回滚环境执行插件/市场/Git/排期（F3）。
5. **P3**：真实键盘输入验证（F4）。
6. **P3**：widgets 确认框玻璃（U2，需拆包）。
7. **P3**：市场入口是否恢复，按产品决策（F1）。
