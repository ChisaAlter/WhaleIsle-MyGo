## Implemented behavior

[The new summary model](../../internal/ui/chat/tool_summary_model.go) projects complete paired call data using current installed toolRowModel rules. For file variants, complete nonempty `file_path` is the primary display field; raw fallback prefers `path`, then `file_path`. Other tool variants prefer the decoded description, followed by the original variant keys and top-level string values in JavaScript Object.values order. Display applies literal case-sensitive cwd-prefix removal then POSIX-only home abbreviation, preserving authored separator/case/dot spelling. Scalar/invalid JSON keeps raw first-line evidence. Summary absence differs from a present empty first line; [header selection](../../internal/ui/chat/tool_row_model.go) respects the model even when empty, while retaining terminal-description precedence.

Header navigation uses a recorded absolute `meta.path` only when the call arguments actually named a path. Otherwise absolute argument paths can link while running or nested; relative arguments link only on successful settled root calls and remain unchanged for the existing session/Host Files opener. Missing root call heads retain callId display without a fabricated metadata-only path; PTC receipt-only data can retain their own arguments. Error/interrupted rows have no active file link. A read offset is taken from valid complete read arguments, including validation of optional positive integer limit, rather than read metadata. No local filesystem reads or normalization derive the model, and no model/event data is modified.

[The header renderer](../../internal/ui/chat/tool_header_summary.go) gives file paths a zero-padding nested ButtonBase with font13/24 at default preferences, minimum width0, shrink1, ellipsis, inherited neutral color and a dotted1DIP underline with3DIP offset derived from native font metrics. Button clicks and focused Enter/Space invoke the existing session-bound opener without changing row expansion. The parent remains independently clickable/focusable, and path navigation also works after opening the body. Read lines use the existing path:line callback representation. Plain short summaries and short links keep suffix/totals nearby; long text shrinks to preserve their nonshrinking content. The native font, underline dot phase and baseline remain different rendering systems; this is no pixel-identity claim.

[Mutation totals](../../internal/ui/chat/tool_diff_summary.go) derive running first-party root write/edit or `str_replace_editor` intent, and successful applied write/edit hunks. Empty/malformed write diff metadata uses the intended complete file; settled edit without valid applied metadata and settled legacy editor calls have no totals. The source schema narrows all applied path/oldText/newText entries without reading disk. Its bounded Myers line edit count matches installed structuredPatch's256edit limit; above the limit, both complete fragments count as replacement, including shared context. Empty text is zero lines, exactly one final LF is a terminator, remaining blanks and CR are content. Multiple hunks sum independently. Zero totals remain meaningful. Totals use code11/24,10DIP margin and.5DIP downshift. They inherit neutral color while resting and show installed green500 `#22c55e` plus the active error token on row hover or expansion; failed/stopped rows suppress size and totals.

Decoded mutation content size covers the original content/old_string/new_string fields, totals their UTF16 code units and rounds up by1024. The suffix uses the installed `{kilobytes}KB` locale text with4DIP margin. [Lifecycle integration](../../internal/ui/chat/tool_lifecycle.go) keeps these additions on main paired conversation rows. Existing addressed read-only history remains passive and retains the original call evidence.

A native accessibility defect found while validating the nested button is fixed in [MyGo's accessible tree](../../third_party/mygo/ui/access.go): disclosure controls continue exposing their role, default label and expansion state while preserving descendant actions. Ordinary buttons remain leaves. [The regression](../../third_party/mygo/ui/access_disclosure_test.go) invokes both path and parent independently and checks that the nested button's decorative text is not duplicated. No generated API or backend change was needed.
