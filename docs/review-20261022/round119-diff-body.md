## Production behavior

[The pure model](../../internal/ui/chat/tool_diff_model.go) selects running root write/edit or legacy create/replace intent, and successful settled write/edit receipts. Preparation, nested calls, stopped/error states, invalid typed args and malformed root receipts decline. Settled edit requires nonempty valid applied diffs. Settled write falls back to its argument-derived whole-file diff when applied metadata is missing, malformed or empty. Settled legacy editor uses Generic. Applied paths remain display strings even when empty/control/URL-like; exact equality to a valid recorded absolute meta.path rewrites only that display path to the model-facing argument spelling. Models confer no file-open authority and consult no disk. [Header totals](../../internal/ui/chat/tool_diff_summary.go) now use the same selection model, preserving their existing bounded count implementation.

[The row builder](../../internal/ui/chat/tool_diff_rows.go) ports the installed jsdiff complete-line linked-component Myers search, including its ambiguous-line tie order, pruned diagonals, three-line context and maxEditLength256. Over the edit bound it renders both complete fragments, including shared lines. There is no legacy256KB skip or line-ID encoding. Empty text is zero content lines; exactly one final LF is a terminator; interior blanks, CR, tabs, CJK and astral Unicode stay intact. Each new path has a header; consecutive same-path fragments and distant local hunks have a verbatim `⋯` gap. An unchanged diff keeps its path-only card. Full clipboard text includes every folded row and uses `- `, `+ ` and two-space context prefixes.

[The primitive](../../internal/ui/widgets/markdown/tool_diffblock.go), [path-language map](../../internal/ui/widgets/markdown/tool_path_language.go), [chat adapter](../../internal/ui/chat/tool_diff.go) and [localized labels](../../internal/ui/i18n/catalog_tool_diff.go) render borderless radius16 cards with code11/19, ordinary42px toolbar,24px controls,14px icons and4px action gap. The banner shows a canonical language only when all path suffixes agree, otherwise localized Code block.

Chat cap9 retains head5/fold/tail4. Expanded content shows all rows then the collapse control. Default unwrapped content scrolls horizontally; wrapped content uses the available width and wraps long words. A column with ScrollOverflowX and measured visible-row minimum width preserves full-row background and moving stripes, even when short rows share a long-line grid. The toolbar stays outside source scrolling. Fold click, Space/Enter and UIAutomation ExpandCollapse are independent from the enclosing row.
