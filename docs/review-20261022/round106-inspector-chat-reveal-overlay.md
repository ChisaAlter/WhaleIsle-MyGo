Inspector selection now reveals loaded Chat content with a separate transient overlay instead of inserting a permanent “Inspector target” text row. A partly visible target stays where it is. A completely invisible target centers vertically, then flashes after150ms without offset movement. The overlay uses the semantic highlight fill, accent outline,6DIP corners and700ms linear opacity keyframes .65→.1→.5→0. Reduced motion centers immediately without a flash. ## Reference and implementation

The source audit read [reveal lifecycle](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/src/client/views/chat-node/reveal.ts), [clipping](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/src/client/views/chat-node/highlight.ts), [DOM candidates](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/src/client/views/chat-node/dom.ts), [target ranking](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/src/client/views/chat-node/reveal-target.ts), [overlay CSS](../../reference/electron/vendor/deepseek-harness/packages/experimental/session-inspector/src/client/views/inspector.module.css) and reference reveal/highlight tests. Source behavior is:any positive clipped area counts as visible, no scroll for partial visibility, otherwise smooth center (instant in reduced mode), then overlay on the clipped rectangle. The reference clips to window/conversation/group bounds and above the composer. It creates the overlay outside the Chat subtree, rounds the clipped result and draws a1px outside outline. Active rectangle is fixed during the pulse.

The native [reveal owner](../../internal/ui/chat/session_inspector_reveal.go) lives in InspectorNavigation, rather than virtual row state. [Chat integration](../../internal/ui/chat/chat.go) collects current painted content bounds after virtual list layout. Visibility is decided only after that paint, so a newly selected Inspector occurrence with no cached bounds cannot incorrectly center an already-visible target. The actual List viewport excludes status/load-earlier and the external composer seat. Per-row geometry excludes message spacing/side padding and respects centered transcript width and native ancestor clips. A fallback uses the current rendered flow extent: short Chat does not highlight empty viewport space. An empty Chat disposes instead of leaving a latent reveal for later unrelated input.

[Target preparation](../../internal/ui/chat/session_inspector.go) retains the navigation while whole-Turn/cluster disclosure is opened and then opens a reasoning row's own body. It uses existing in-memory disclosure choices only, without fetching source data. After current-paint visibility decides a center is needed, it queues an identity rather than a List ordinal. Each build before layout resolves the current key against the current visible projection; a prepend or unrelated disclosure change cannot center a stale row number. An issued-but-uncommitted center is owned until the next paint. Cancellation overwrites it with the prior painted offset so a discarded build pass cannot leave a late scroll behind. Binding changes, replacements and owner handoff use the same cleanup.

[Main window composition](../../cmd/whaleisle/main.go) now passes the address of its persistent Chat ListState through to the frame and removes pre-layout value-copy writeback. List layout runs after mainView returns; copying the state before layout retained stale scroll requests and lost layout results. A stable owner is also necessary for deferred center cancellation across the engine's build passes. All known reads/writes of this field were reviewed: initialization remains on the UI thread, no background caller was introduced. This round changes no toolkit/backend code.

The [frame arbitration](../../internal/ui/frame/session_inspector_navigation.go) cancels every nonchosen reveal, including requests already consumed from Target. [Page lifecycle](../../internal/ui/frame/workspace_content.go) disposes when main Chat is no longer displayed. The fixed window-level overlay is pass-through, has no text/role/focus, is painted after Chat text, and adds no layout height. Fill radius6 and expanded outline rectangle radius7 emulate the outside1DIP accent stroke. It uses the theme's BubbleHighlight role added in Round105. Opacity interpolates at equal offsets0,1/3,2/3,1; fill and outline change together. Painter.AnimationFrame animates without rebuilding the transcript. Expiry clears the owner and cannot replay from old scheduled paints. New requests clear prior state, preventing an older completion from deleting a replacement.
