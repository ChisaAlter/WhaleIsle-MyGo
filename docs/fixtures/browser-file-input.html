E01: ordinary browser file input

Serve this fixture on an authorized local HTTP origin and open it in the ordinary browser panel, not an isolated document preview. Select synthetic non-sensitive files only. This page sends no network requests and never reads full filesystem paths.

Check single selection, multiple selection, cancelling an empty picker, cancelling after a selection, reselecting the same file, and keyboard activation. Record Windows and WebView2 versions. This fixture checks file delivery and multipart serialization, not a real server upload.
