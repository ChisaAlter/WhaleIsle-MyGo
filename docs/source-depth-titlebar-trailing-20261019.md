## Follow-up: one-click Initialize and global-page review ownership

Pinned `GitActionsControl.tsx:471` directly invokes `gitInit(cwd)` from the captured click, with progress/busy, failure reporting and status refresh. For global-page actions root passes `overlay=true` to CaptionAction and `diffsurface.Model.CaptionAdmission` as its captured window/Host/retained-Session validity closure. The one window Workbench receives only a private presentation seat containing root/action/kind/admission; no review state, file selection, plan, or operation is cloned. `CaptionReview(c,diffModel)` mounts the original selected-commit, remote and publish review controls in the root modal. Merely showing the modal does not prepare a message, generate copy, or run Git. It captures the cwd, rechecks admission and cwd before drawing action controls, and the shared prepare/confirm/model-generation entries also recheck admission. A changed Host/Session/root retires that seat and cancels its preparation; an already captured mutation is never silently canceled or redirected.

Root must call CaptionReview on every page, including normal workspace after a global action opened the modal. While a valid caption modal exists, paintWorkbench suppresses the duplicate inline controls. `Workbench.CaptionReviewOpen()` lets root call CaptionActivity when that modal owns the controls even if an actual Diff pane exists; otherwise keep exactly one existing inline/overlay progress producer. Closing the modal revokes only its own preparation, not an in-flight mutation. `init` does not open the modal or force a dock/page change. Root owns the new API wiring and source-state producers.
