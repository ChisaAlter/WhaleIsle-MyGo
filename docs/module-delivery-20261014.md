## 构建
使用 Go 模块依赖，Windows amd64、CGO_ENABLED=0，运行 go build -o <源码目录外的路径>/whaleisle.exe ./cmd/whaleisle。go.mod 将 MyGo 指向仓库内 third_party/mygo；保留上游许可证和实现所需补丁，因此不依赖交付机器的绝对路径。
