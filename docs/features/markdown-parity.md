# 聊天 Markdown 图文与增量渲染

助手正文中的 Markdown 图片和旧 `[image] path` 附件行按原文位置绘制，前后段落、同一行多张图片及重复图片均保留各自位置。原生 image content block 继续沿会话投影的块顺序绘制，用户消息保留字面文本气泡与原有附件条。图片加载、附件缓存、失败反馈及灯箱仍由既有图片视图负责。

图片目的地解析共用 `internal/markdownsyntax` 中的 Goldmark 语法，支持平衡括号、尖括号包裹的空格路径、带标题图片及引用图片。对以 `/`、`./`、`../` 或 Windows 盘符开始的本地空格图片路径有局部恢复；代码围栏、行内代码和转义示例不作为图片。prompt 图片转换使用同一语法记录的源范围，避免将右括号或标题泄漏回文本；多张 image-only 图片不会只留下第一张。

显式本地 Markdown 链接支持 `#L24`、`#L24-L30` 和 `:24`，范围在首行打开。路径解码一次，URL、UNC、query、控制字符、不完整 percent escape 和倒序行号保持不可激活。文件打开继续使用原来的 `OnOpenDeliverable` 与 Files/Host 路径，保留发起会话绑定、真实 cwd、符号链接检查、草稿和分页行号导航。inline-code 文件提示仍只使用已记录的同轮文件事实。流式消息的本地链接和 inline-code 文件提示在结束后才启用。

脚注使用 Goldmark Footnote 扩展：上标按首次引用顺序编号，重复引用复用编号，未定义引用保持字面文本，未引用定义不显示。末尾脚注区域保留多段正文与每次引用对应的回指标记；回指标记为文字，不引入外部或 fragment 导航。

`math` 围栏在流结束后作为 display TeX 交给现有离线 MathJax；原有 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]` 行为保留。流式阶段的 TeX 保持字面源码，结束后完整重解析，避免半截公式提交给离线进程。MathJax 的向量输出、进程限制与不安全公式拒绝未改动。

文档视图保留每条消息的解析状态。追加文本时冻结尾部两块之前的稳定顶层块，按语法记录的源位置分配稳定 key；消息替换或流结束时重新完整解析。未闭合的顶层代码围栏另保留已完成行，只把当前不完整行及新行交回语法；围栏关闭后恢复普通解析。源切片复制为有界片段，避免每个冻结批次持有旧完整回复。段落间距、标题、引用、表格、代码换行选择与 fence 的整篇绝对 offset 沿用原有布局。

Chroma 的公开接口不能恢复任意词法器栈，所以流式代码高亮使用倍增长度检查点：检查点完整着色，其后新增源码立即以等宽文字显示，下一个检查点重新着色，结束时完整重着色。测试计数的是实际交给 Goldmark/Chroma 的输入字节，不以相同文本缓存代替追加测试。流式跨冻结位置的引用定义和脚注在结束时完整解析修复；含已解析脚注列表的尾部保持整体，保证流式编号不重复，该类尾部不保证与普通段落相同的有界解析量。

2026-10-25 最终验证使用 `scripts/run-hidden.ps1` 的隐藏控制台 runner，脚本先点源 `scripts/env.ps1`，chat fixtures 和脚本均将 `WHALEISLE_USER_DATA` 指向隔离目录。`tmp/markdown-final.log` 记录 exit 0：`internal/markdownsyntax` 0.932s、`internal/ui/widgets/markdown` 整包 2.459s、`internal/mathrender` 实际离线 MathJax 整包 3.492s、session 图片/assistant 回归 3.045s、聊天图文顺序/文件点击/用户气泡/文件提示 2.843s，以及 Files 行号分页/绑定/草稿测试 2.410s。逐字测试覆盖 CRLF 拆分、围栏闭合与 setext 标题，操作测试覆盖换行选择跨冻结/结束保留、本地链接结束后才激活、图片链接保留目的地。`git diff --check` 通过。
