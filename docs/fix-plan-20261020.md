# 全面修复计划：MyGo鲸屿 vs 原版鲸屿（2026-10-20 起）

依据：[UI 对比审查总报告](ui-parity-review-20261020.md)（103 条、19 条 P0、5 条根因）。
目标：按 Phase A → B → C 把差距收敛到"同条件截图基本一致、用户日常使用不再有断层"。

## 团队与写入域（必须遵守，避免并发冲突）

| 角色 | 修复域 | 允许写入（其他一律不动） |
| --- | --- | --- |
| **primitives-fixer** | 设计原语层 | `internal/ui/widgets/*.go`（包根，新文件为主）；可最小改动 `widgets.go` |
| **shell-nav-reviewer** | 外壳/侧栏/标题/boot | `internal/ui/{sidebar,frame,chrome,boot,launcher}/**`、`internal/store/session/title.go`、`internal/store/session/workspace_rpc.go` |
| **conversation-reviewer** | 对话/消息/Markdown | `internal/ui/chat/**`、`internal/ui/interaction/**`、`internal/ui/widgets/markdown/**`、`internal/ui/i18n/catalog_chat.go` |
| **composer-reviewer** | 输入区/状态行 | `internal/ui/composer/**`、`internal/ui/sessioncost/**`、`internal/ui/i18n/catalog_composer.go` |
| **surfaces-reviewer** | 设置/文件/Diff/用量 | `internal/ui/{settings,files,diffsurface,usage,terminal}/**`、`internal/ui/i18n/catalog_surfaces.go` |
| **Lead** | 协调、i18n 基座、材质/默认外观、验收 | `internal/ui/i18n/i18n.go`、`docs/**`、跨域文件；负责最终 git 提交 |

- **共享文件例外**：`internal/ui/frame/frame.go` 归 shell；hero 相关改动由 Lead 在 shell 提交后统一安排。
- **每个域自己的 i18n 目录文件**：在 `internal/ui/i18n/catalog_<area>.go` 里定义 key 常量并在 `init()` 调 `i18n.Register(key, 中文, English)`，**不要**再改 `i18n.go` 的 map 字面量。消费方用 `i18n.T(i18n.KeyXxx)`。
- **不要运行写 git 的命令**（add/commit/checkout），提交由 Lead 统一做。
- **不要对既有文件跑 `gofmt -w`**：仓库工作区是 CRLF，gofmt 会把整文件转 LF 造成巨大 diff。新文件可以格式化。

## 验证要求（每个 agent 自测后回报）

1. `go build ./cmd/... ./internal/...` 通过（不要用 `go build ./...`，`tmp/` 里有历史 scratch 文件会挂）。
2. 受影响包 `go test ./internal/ui/<pkg>` 通过；为新原语/新交互补最小测试。
3. 不引入新的 `"中文 / English"` 双写；新增文案走 Register。
4. 完成项回报格式：`[done] 条目 → 文件 → 验证命令与结果`；未完成写 `[blocked] 原因`。

## Wave 1（本轮并行）

### W1-P primitives：原语层（P0 根因）

- `DisclosureRow`：图标 + 标题 + 2px 圆点分隔 + 截断摘要 + chevron，整行可点，24px 行高，hover 底色，键盘可达（Enter/Space）。
- `StateDot`：idle/running/done/warning/error 五态，10px 槽、6px 实心、running 呼吸环。
- `SwitchRow`：36×20 switch（主题色、thumb 16px、`:focus-visible` 环）+ 行式设置布局原语（标题 14/22 + 描述 12/18 + 右侧控件 + 0.5px 分隔线）。
- `ConfirmDialog`：应用内 `DialogBase` 模态（标题/正文/主次按钮/危险色），替代系统 MessageBox 的基础件。
- `TextShimmer`：运行中扫光（Painter 实现，尊重 reduced motion）。
- motion token：时长/缓动常量（overlay 200ms、popover 150ms、swap 120ms、flip 300ms，ease-in-out）。
- 验收：`go test ./internal/ui/widgets`；每个原语一个 tester 测试；在包文档里写明用法。

### W1-C conversation：对话层（P0）

- Markdown 块级排版：标题外边距阶梯、段落行高、真实列表缩进、引用左边线、行内代码 chip、表格自动列宽 + 表头底色。
- 代码块：深浅两套 chroma、图标工具栏（换行/复制）、复制对勾反馈、语言标签、可选行号。
- 工具行：改为单行 disclosure（用 primitives 的 DisclosureRow；未就绪时先做本地行），保留终端/差异/读取/检索的结构化展开。
- 思考/用量/回合行：接 StateDot + Shimmer + 耗时；`formatTurnStatus` 真正上屏。
- 移除 `workspace ready:` 正文泄漏（配合 shell 的 store 改动）。
- 本地化：`catalog_chat.go` + 替换 chat/interaction 内 176 处双写（本波至少完成最常显示的 60 处，剩余列清单）。

### W1-S shell：外壳与导航（P0）

- 侧栏品牌锁：38px 头像、`鲸屿` 18/700、`MYGO鲸屿` 10/600、`BASED ON DEEPSEEK HARNESS` 8/500；删除重复名称行。
- 左下账号区：24px 头像 + 名称 + 菜单（账号设置/退出登录），折叠态 36×36；复用现有 `OnContactAccount`/`state.accountSignOut` 通道。
- 标题带：单行 48px（Windows），默认不渲染 13px 标签行；未命名会话显示本地化"新会话"而不是 session id；右侧动作簇 top 12 / gap 8。
- 侧栏顶部与 footer 上沿加 `DragWindow()`；`frame_ring` 跟随主题并在最大化时去掉。
- store：`title.go` 未命名不再拼 id；`workspace_rpc.go` 不把 `workspace ready:` 写进 lastAction。

### W1-M composer：输入区（P0/P1）

- 权限 pill：Host 值→产品名（`read-only` 仅可查看 / `workspace-write` 工作区内修改 / `danger-full-access` 完全权限），28px chip、盾牌图标、chevron 旋转、hover/焦点环。
- 模型 seat：28px chip + chevron + 强度次色；加载中/未选择文案。
- dock 状态行：居中两簇统计 pill（轮/步/tok/s、tokens/缓存命中），数字紧凑化（77.7M、99.7%），走 Register 单语。
- 上下文环：14px 双环 + 百分比；缺数据时占位 `—%`，不整块消失；颜色走主题 token。
- `/` `@` 弹层：浮到卡片上方（Popover），320/400 上限、阴影、34px 行、hover 高亮、Tab 键帽。
- 发送/加号/停止 hover/pressed 反馈；输入卡 Radius 28 + 内侧白高光。

### W1-F surfaces：功能界面（P0）

- 设置：`fieldRow` 改为行式（标题左/控件右/0.5px 分隔线）并复用 `bodyPreferenceRow`；布尔项换 `ui.Switch` 有标签；设置导航去掉"实现命名空间"分区。
- 文件标签：横向 28px chip 条（active 底色、hover 出 close、标题渐变遮罩、末尾 +）；删除 ▸/• 字符状态。
- Diff：20px 行高、12px 行号槽、±8% 行底色、hunk 圆角头。
- 用量：KPI 卡 + 环图 + 贡献日历 + 排行卡替换文本墙；数字紧凑格式。
- 应用内确认框：设置替换/Git 推送/插件导入 3 处先迁（用 primitives 的 ConfirmDialog）。

## Wave 2（Wave 1 验收后）

hero 与标题带联动、默认外观（深色 + 壁纸）、表面材质与菜单模糊、指针特效/金属漆实现或隐藏、boot 场景、64 处系统弹框迁移、窄宽抽屉、终端标签、Git 对话框、本地化剩余项、同条件截图验收。

## 验收门槛（每波）

1. `go build ./cmd/... ./internal/...` + 受影响包测试全绿。
2. 新增测试覆盖新原语与新交互；不出现新的双语硬编码。
3. Lead 抽查 5 条 P0 的 `file:line`，确认与审查证据一致。
4. 更新本文件"进度"表，并在总报告里标记已关闭条目。
